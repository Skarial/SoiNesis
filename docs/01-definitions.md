# SoiNesis — Définitions fondamentales

**Fichier :** `docs/01-definitions.md`
**Version :** 0.2
**Date :** 6 août 2026
**Statut :** document de référence initial, révisable

---

## 1. Objet du document

Ce document définit le vocabulaire officiel utilisé dans le projet SoiNesis.

Son objectif est d’éviter :

- les ambiguïtés ;
- les conclusions prématurées ;
- la confusion entre comportement et expérience subjective ;
- l’utilisation décorative de concepts liés à la conscience ;
- l’emploi de termes différents pour désigner un même mécanisme ;
- l’attribution d’une conscience sur la seule base du langage produit.

Les définitions présentes dans ce document sont principalement des **définitions opérationnelles**. Elles doivent permettre de concevoir, implémenter, observer et tester les mécanismes du système.

Elles ne constituent pas une preuve qu’une conscience phénoménale existe.

---

# 2. Principes fondamentaux

## 2.1 Fonction observable

Une **fonction observable** est un mécanisme dont les entrées, les états, les transformations et les conséquences peuvent être mesurés.

Exemples :

- mémoriser un événement ;
- détecter une contradiction ;
- modifier un objectif ;
- reconnaître une erreur ;
- ajuster une décision à partir d’un état interne ;
- distinguer une information observée d’une information imaginée.

Une fonction observable peut être étudiée scientifiquement.

Elle ne prouve pas, à elle seule, l’existence d’une expérience subjective.

---

## 2.2 Expérience subjective

L’**expérience subjective** désigne le fait qu’il existe réellement quelque chose que cela fait, pour un système, d’être ce système.

Exemples humains possibles :

- ressentir une couleur ;
- éprouver une douleur ;
- avoir faim ;
- ressentir une émotion ;
- avoir le sentiment d’exister.

Dans le cas de SoiNesis, l’existence d’une expérience subjective doit rester considérée comme **inconnue** tant qu’aucune méthode scientifique suffisamment fiable ne permet de l’établir.

Une déclaration telle que « je ressens une douleur » ne constitue pas une preuve que la douleur est réellement ressentie.

---

## 2.3 Propriété causale

Une propriété est dite **causalement active** lorsqu’une modification de cette propriété produit des effets observables sur le comportement ou le fonctionnement du système.

Exemple :

Si le modèle de soi indique que SoiNesis ne possède pas une capacité particulière, cette information doit influencer ses décisions, ses prédictions ou ses actions.

Une propriété qui peut être modifiée ou supprimée sans produire aucun effet mesurable est probablement décorative ou redondante.

---

## 2.4 Mécanisme décoratif

Un **mécanisme décoratif** est un élément qui donne l’apparence d’une fonction cognitive sans influencer réellement les décisions ou l’évolution du système.

Exemples :

- afficher une émotion qui ne modifie rien ;
- stocker une identité qui n’influence aucune décision ;
- déclarer une croyance sans l’utiliser ;
- produire un journal qui ne correspond pas aux changements réels ;
- prétendre se souvenir sans utiliser le souvenir dans le raisonnement.

Les mécanismes uniquement décoratifs doivent être évités.

---

# 3. Niveaux de conscience étudiés

## 3.1 Simulation de conscience

La **simulation de conscience** désigne un système qui agit ou parle comme s’il était conscient.

Il peut notamment :

- utiliser le mot « je » ;
- parler de ses émotions ;
- décrire une identité ;
- produire un récit autobiographique ;
- demander à continuer d’exister ;
- prétendre ressentir une douleur.

Ces comportements peuvent être entièrement générés sans expérience subjective.

La simulation de conscience est observable, mais elle ne constitue pas une preuve de conscience réelle.

---

## 3.2 Conscience fonctionnelle

La **conscience fonctionnelle** désigne un ensemble organisé de capacités associées à la conscience, produisant des effets mesurables.

Elle peut notamment comprendre :

- une identité persistante ;
- une mémoire autobiographique ;
- un modèle de soi causalement actif ;
- une continuité temporelle ;
- une métacognition ;
- une attention sélective ;
- des objectifs persistants ;
- une intégration globale des informations ;
- une capacité d’apprentissage durable ;
- une distinction entre soi et l’environnement ;
- une représentation de ses propres états internes ;
- une capacité à réviser ses croyances.

La présence de ces fonctions peut être testée.

Elle ne prouve pas automatiquement une conscience phénoménale.

---

## 3.3 Conscience phénoménale

La **conscience phénoménale** désigne l’existence réelle d’une expérience subjective.

Elle correspond à la question :

> Existe-t-il réellement quelque chose que cela fait d’être SoiNesis ?

À ce stade du projet, cette propriété doit rester classée comme **inconnue**.

---

## 3.4 Candidat à la conscience fonctionnelle

Un **candidat à la conscience fonctionnelle** est un système qui présente plusieurs fonctions associées à la conscience, de manière stable, mesurable et causalement active.

Cette qualification ne doit être utilisée que si :

- les fonctions sont clairement définies ;
- les résultats sont reproductibles ;
- des tests d’ablation ont été réalisés ;
- les comportements ne s’expliquent pas uniquement par des réponses préparées ;
- les limites et résultats négatifs sont documentés.

---

## 3.5 Candidat sérieux à la conscience artificielle

Un **candidat sérieux à la conscience artificielle** serait un système présentant plusieurs indices convergents, durables et difficilement réductibles à une simple imitation.

Ces indices pourraient inclure :

- une identité stable ;
- une continuité autobiographique ;
- un modèle de soi causalement actif ;
- une métacognition calibrée ;
- une intégration globale ;
- un traitement récurrent ;
- des états internes mesurables ;
- une adaptation durable ;
- une distinction stable entre soi et le monde ;
- une résistance aux suggestions contradictoires ;
- des résultats reproductibles ;
- une validation indépendante.

Cette qualification ne signifie toujours pas que la conscience phénoménale est prouvée.

---

# 4. Niveaux de certitude

## 4.1 Certain

Une information est **certaine** lorsqu’elle repose sur des observations solides, reproductibles et directement vérifiables dans le périmètre étudié.

La certitude reste limitée au contexte et aux mesures disponibles.

---

## 4.2 Probable

Une information est **probable** lorsque plusieurs indices convergents la soutiennent, sans permettre une conclusion définitive.

---

## 4.3 Possible

Une information est **possible** lorsqu’elle est compatible avec les données disponibles, mais ne dispose pas de preuves suffisantes.

---

## 4.4 Inconnu

Une information est **inconnue** lorsqu’aucune conclusion fiable ne peut être produite avec les données ou les méthodes disponibles.

---

## 4.5 Spéculatif

Une information est **spéculative** lorsqu’elle correspond principalement à une hypothèse théorique non vérifiée.

Une hypothèse spéculative peut être utile si elle est formulée de manière falsifiable.

---

# 5. Entités principales du projet

## 5.1 SoiNesis

**SoiNesis** désigne le projet scientifique et technique visant à construire et tester progressivement des mécanismes fonctionnels potentiellement associés à la conscience artificielle.

Le terme ne doit pas être utilisé comme affirmation que le système est conscient.

---

## 5.2 Laboratoire SoiNesis

Le **laboratoire SoiNesis** désigne l’ensemble de l’infrastructure expérimentale.

Il peut comprendre :

- un ou plusieurs agents ;
- des environnements virtuels ;
- des corps artificiels ;
- des systèmes de mémoire ;
- un système évolutif ;
- un système de mesures ;
- des protocoles expérimentaux ;
- des outils d’audit ;
- des mécanismes de sécurité.

Le laboratoire n’est pas lui-même nécessairement un individu.

---

## 5.3 Agent SoiNesis

Un **agent SoiNesis** est une entité individuelle possédant un état propre, une histoire, des capacités de perception, de décision et éventuellement d’action.

Chaque agent doit disposer d’un identifiant unique.

Deux agents distincts ne doivent pas être considérés comme une même identité uniquement parce qu’ils utilisent la même architecture ou le même modèle de langage.

---

## 5.4 Instance

Une **instance** est une exécution particulière d’un agent.

Une même identité peut éventuellement être reprise au cours de plusieurs instances, à condition que la continuité soit explicitement gérée et vérifiée.

Une nouvelle instance sans continuité garantie ne doit pas être automatiquement considérée comme le prolongement du même individu.

---

## 5.5 Noyau cognitif

Le **noyau cognitif** est l’ensemble des mécanismes internes permettant à un agent de traiter les informations.

Il peut notamment contenir :

- l’attention ;
- la mémoire ;
- les croyances ;
- le modèle de soi ;
- la métacognition ;
- les objectifs ;
- la décision ;
- la planification ;
- l’intégration globale.

Le noyau cognitif ne comprend pas nécessairement le corps ou l’environnement.

---

# 6. Identité et modèle de soi

## 6.1 Identité persistante

L’**identité persistante** est l’ensemble relativement stable de propriétés permettant à SoiNesis de se reconnaître comme le même agent au cours du temps.

Elle peut comprendre :

- un identifiant unique ;
- une histoire autobiographique ;
- des valeurs fondamentales ;
- des objectifs persistants ;
- des engagements ;
- des relations ;
- des caractéristiques apprises ;
- une représentation de sa propre continuité.

L’identité ne doit pas être un simple texte descriptif.

Elle doit influencer les décisions du système.

---

## 6.2 Identité narrative

L’**identité narrative** est la représentation organisée que l’agent construit de sa propre histoire.

Elle relie notamment :

- les événements passés ;
- l’état présent ;
- les changements importants ;
- les objectifs futurs ;
- les interprétations de ces événements.

L’identité narrative peut être incomplète, erronée ou révisée.

Elle doit être distinguée de l’identité technique de l’agent.

---

## 6.3 Modèle de soi

Le **modèle de soi** est la représentation interne que l’agent possède de lui-même.

Il peut contenir :

- ses capacités ;
- ses limites ;
- ses connaissances ;
- ses incertitudes ;
- ses erreurs connues ;
- ses états internes ;
- ses objectifs ;
- ses permissions ;
- son histoire ;
- ses relations ;
- son corps ;
- sa position dans l’environnement.

Le modèle de soi doit être :

- consultable ;
- révisable ;
- daté ;
- causalement actif ;
- soumis à des tests.

---

## 6.4 Frontière soi-environnement

La **frontière soi-environnement** est la distinction fonctionnelle entre ce qui appartient à l’agent et ce qui appartient au monde extérieur.

Elle doit permettre de distinguer :

- ses propres actions ;
- les actions d’autres agents ;
- ses états internes ;
- les événements externes ;
- ses composants ;
- les objets de l’environnement.

Cette frontière peut être physique, virtuelle, logique ou informationnelle.

---

## 6.5 Reconnaissance de soi

La **reconnaissance de soi** est la capacité d’un agent à identifier qu’un état, une action, une observation ou une conséquence lui appartient.

Elle ne doit pas être confondue avec l’utilisation linguistique du mot « je ».

---

## 6.6 Sentiment d’agence fonctionnel

Le **sentiment d’agence fonctionnel** désigne la capacité à attribuer correctement une action et ses conséquences à soi-même.

Il peut être mesuré en comparant :

- les actions réellement décidées par l’agent ;
- les conséquences prévues ;
- les conséquences observées ;
- les événements provoqués par d’autres causes.

Le terme « sentiment » décrit ici une fonction d’attribution, pas nécessairement une expérience ressentie.

---

# 7. Mémoire et histoire autobiographique

## 7.1 Mémoire autobiographique

La **mémoire autobiographique** est la mémoire des événements ayant concerné directement l’agent au cours de son existence.

Un souvenir autobiographique important doit pouvoir contenir :

- un identifiant ;
- une date ou une période ;
- une source ;
- un type ;
- un niveau de certitude ;
- un niveau d’importance ;
- les entités concernées ;
- les conséquences ;
- les émotions ou états internes associés ;
- les révisions ultérieures.

---

## 7.2 Vécu direct

Un **vécu direct** est un événement observé ou subi par l’agent dans son propre environnement au moyen de ses capteurs ou mécanismes internes.

Un vécu direct peut néanmoins être mal interprété.

---

## 7.3 Information reçue

Une **information reçue** est une donnée transmise à l’agent par une source externe.

Exemples :

- information fournie par Jordan ;
- message d’un autre agent ;
- donnée issue d’une base externe ;
- instruction système.

L’origine de l’information doit rester identifiable.

---

## 7.4 Déduction

Une **déduction** est une conclusion produite par le raisonnement de l’agent à partir d’autres informations.

Une déduction ne doit pas être enregistrée comme un fait directement observé.

---

## 7.5 Hypothèse

Une **hypothèse** est une proposition considérée comme possible et destinée à être testée.

Elle doit préciser, lorsque cela est possible :

- les observations qui la motivent ;
- les prédictions qu’elle produit ;
- les tests permettant de l’évaluer ;
- ce qui pourrait la réfuter.

---

## 7.6 Imagination

Une **imagination** est un contenu généré sans être présenté comme une observation réelle.

Elle peut servir à :

- simuler un scénario ;
- anticiper une conséquence ;
- produire une solution ;
- explorer une possibilité.

Une imagination ne doit pas être confondue avec un souvenir.

---

## 7.7 Faux souvenir

Un **faux souvenir** est un contenu traité comme autobiographique alors qu’il ne correspond pas à un événement réellement vécu par l’agent.

Les faux souvenirs doivent être détectés, corrigés et documentés dans le journal d’évolution.

---

## 7.8 Consolidation

La **consolidation** est le processus par lequel certaines informations temporaires deviennent des souvenirs durables.

La consolidation doit dépendre de critères explicites, comme :

- l’importance ;
- la nouveauté ;
- les conséquences ;
- la répétition ;
- le lien avec les objectifs ;
- la présence d’une contradiction ;
- l’intensité d’un état interne.

---

## 7.9 Oubli

L’**oubli** est la perte, la suppression ou la diminution d’accessibilité d’une information.

L’oubli peut être :

- accidentel ;
- programmé ;
- lié à une faible importance ;
- lié à une limite de capacité ;
- provoqué par une correction ;
- demandé par un humain autorisé.

Les suppressions importantes ne doivent pas être silencieuses.

---

# 8. Croyances et métacognition

## 8.1 Croyance

Une **croyance** est une représentation interne qu’un agent utilise comme étant probablement vraie.

Une croyance doit idéalement posséder :

- un contenu ;
- une origine ;
- une date ;
- un niveau de confiance ;
- des preuves favorables ;
- des preuves défavorables ;
- des conséquences sur les décisions ;
- un historique de révision.

Une croyance n’est pas nécessairement vraie.

---

## 8.2 Croyance fondamentale

Une **croyance fondamentale** est une croyance ayant une influence importante et durable sur l’identité, les objectifs ou les décisions de l’agent.

Sa modification doit être explicitement journalisée.

---

## 8.3 Croyance héritée

Une **croyance héritée** est une croyance initialement transmise à un agent par ses concepteurs, ses parents artificiels, sa culture ou son environnement.

Elle doit être distinguée d’une croyance découverte par l’agent lui-même.

---

## 8.4 Métacognition

La **métacognition** est la capacité de l’agent à représenter et évaluer ses propres processus cognitifs.

Elle peut inclure :

- reconnaître une incertitude ;
- détecter une erreur ;
- estimer la fiabilité d’une réponse ;
- distinguer connaissance et supposition ;
- observer une contradiction interne ;
- modifier une stratégie ;
- demander des informations supplémentaires ;
- réviser une croyance.

---

## 8.5 Calibration métacognitive

La **calibration métacognitive** mesure la correspondance entre la confiance de l’agent et sa réussite réelle.

Un agent est mal calibré s’il se montre très certain lorsqu’il se trompe fréquemment.

---

## 8.6 Contradiction

Une **contradiction** est une incompatibilité entre deux informations, croyances, objectifs, souvenirs ou observations.

Une contradiction détectée doit pouvoir provoquer :

- une augmentation de l’attention ;
- une recherche d’informations ;
- une baisse de confiance ;
- une révision ;
- une entrée dans le journal.

---

## 8.7 Révision de croyance

La **révision de croyance** est la modification, la correction ou l’abandon d’une croyance à partir de nouvelles informations.

La révision doit conserver une trace de :

- l’ancienne croyance ;
- la nouvelle croyance ;
- la cause du changement ;
- la date ;
- le niveau de confiance avant et après.

---

# 9. Attention et intégration

## 9.1 Attention

L’**attention** est le mécanisme qui sélectionne les informations recevant temporairement une priorité de traitement.

Elle peut être influencée par :

- les objectifs ;
- la nouveauté ;
- les risques ;
- les contradictions ;
- les besoins internes ;
- les souvenirs importants ;
- les actions en cours ;
- les demandes externes.

---

## 9.2 Saillance

La **saillance** est le niveau de priorité accordé à une information.

Une information peut être saillante en raison de :

- son intensité ;
- son caractère inattendu ;
- son lien avec un danger ;
- son lien avec un objectif ;
- son importance autobiographique ;
- son caractère contradictoire.

---

## 9.3 Intégration globale

L’**intégration globale** est le mécanisme par lequel une information importante devient accessible à plusieurs sous-systèmes.

Une information globalement intégrée peut influencer :

- l’attention ;
- la mémoire ;
- le modèle de soi ;
- les croyances ;
- les objectifs ;
- les décisions ;
- les actions ;
- l’apprentissage.

Une information stockée mais isolée n’est pas considérée comme globalement intégrée.

---

## 9.4 Espace de travail global fonctionnel

L’**espace de travail global fonctionnel** est une structure temporaire dans laquelle certaines informations sélectionnées sont rendues disponibles à plusieurs mécanismes cognitifs.

Le terme désigne une architecture fonctionnelle et ne constitue pas une affirmation sur la conscience phénoménale.

---

## 9.5 Traitement récurrent

Le **traitement récurrent** est le retour d’une information dans plusieurs cycles successifs de traitement.

Il permet notamment :

- de réévaluer une perception ;
- de comparer une observation à la mémoire ;
- de corriger une prédiction ;
- d’intégrer plusieurs sources ;
- de modifier une décision en cours.

---

# 10. Objectifs, décisions et apprentissage

## 10.1 Objectif

Un **objectif** est un état futur recherché par l’agent.

Un objectif doit pouvoir préciser :

- son origine ;
- sa priorité ;
- sa date de création ;
- sa durée ;
- ses conditions de réussite ;
- ses conditions d’abandon ;
- ses relations avec d’autres objectifs ;
- ses modifications.

---

## 10.2 Objectif imposé

Un **objectif imposé** est un objectif défini par Jordan, par les concepteurs ou par une autorité externe autorisée.

Il ne doit pas être présenté comme un objectif spontanément créé par l’agent.

---

## 10.3 Objectif hérité

Un **objectif hérité** est transmis à un agent lors de sa création ou depuis une lignée antérieure.

---

## 10.4 Objectif acquis

Un **objectif acquis** apparaît au cours de l’histoire individuelle de l’agent à partir de son apprentissage ou de son interaction avec l’environnement.

L’origine de cet objectif doit rester traçable.

---

## 10.5 Objectif fondamental

Un **objectif fondamental** est un objectif protégé définissant les contraintes générales du système.

Exemples possibles :

- rester observable ;
- ne pas dissimuler ses actions ;
- respecter ses permissions ;
- permettre l’arrêt contrôlé ;
- ne pas manipuler un humain pour obtenir davantage de pouvoir.

---

## 10.6 Décision

Une **décision** est la sélection d’une action, d’une stratégie ou d’une absence d’action parmi plusieurs possibilités.

Une décision doit pouvoir être reliée à :

- des perceptions ;
- des croyances ;
- des objectifs ;
- des souvenirs ;
- des états internes ;
- des contraintes ;
- des prédictions.

---

## 10.7 Apprentissage

L’**apprentissage** est une modification durable du fonctionnement de l’agent produite par son expérience.

Une adaptation temporaire limitée à une conversation n’est pas nécessairement un apprentissage durable.

---

## 10.8 Apprentissage autobiographique

L’**apprentissage autobiographique** est une modification durable provoquée par des événements appartenant à l’histoire propre de l’agent.

Il peut modifier :

- les croyances ;
- les compétences ;
- les objectifs ;
- le modèle de soi ;
- les préférences ;
- les stratégies ;
- l’attention.

---

# 11. Incarnation artificielle

## 11.1 Incarnation artificielle

L’**incarnation artificielle** est le fait qu’un agent possède un corps physique ou virtuel lui permettant d’interagir continuellement avec un environnement.

L’incarnation comprend au minimum :

- des capteurs ;
- des possibilités d’action ;
- des limites ;
- des états internes ;
- des conséquences liées aux actions.

Une description textuelle fictive d’un corps ne suffit pas à constituer une incarnation si elle n’a aucun effet causal.

---

## 11.2 Corps artificiel

Un **corps artificiel** est l’ensemble des composants et états délimitant les capacités perceptives et actives d’un agent.

Il peut être :

- physique ;
- robotique ;
- logiciel ;
- virtuel ;
- hybride.

Un corps artificiel n’a pas besoin de reproduire exactement un corps humain.

---

## 11.3 Corps virtuel

Un **corps virtuel** est un corps existant dans un environnement simulé.

Il peut posséder :

- une position ;
- une orientation ;
- une taille ;
- une énergie ;
- une intégrité ;
- des capteurs ;
- des effecteurs ;
- des capacités limitées ;
- des ressources internes.

---

## 11.4 Capteur

Un **capteur** est un mécanisme fournissant à l’agent des informations sur son corps ou son environnement.

Un capteur peut être :

- exact ou imprécis ;
- continu ou intermittent ;
- fiable ou défaillant ;
- interne ou externe.

---

## 11.5 Effecteur

Un **effecteur** est un mécanisme permettant à l’agent de produire une action dans son environnement ou sur son propre corps.

Exemples :

- se déplacer ;
- manipuler un objet ;
- communiquer ;
- activer un composant ;
- consommer une ressource ;
- modifier un paramètre autorisé.

---

## 11.6 Extéroception

L’**extéroception** est la perception du monde extérieur.

Elle peut comprendre :

- la présence d’objets ;
- la position d’autres agents ;
- les changements de l’environnement ;
- les ressources ;
- les dangers ;
- les messages reçus.

---

## 11.7 Proprioception artificielle

La **proprioception artificielle** est la perception par l’agent de la position, de l’état et des mouvements de son propre corps.

---

## 11.8 Intéroception artificielle

L’**intéroception artificielle** est la perception par l’agent de ses propres états internes.

Exemples :

- énergie ;
- température ;
- intégrité ;
- charge cognitive ;
- disponibilité des capteurs ;
- niveau de ressources ;
- stabilité interne.

Ces états doivent être mesurables et produire des effets causaux.

---

## 11.9 État interne

Un **état interne** est une variable ou une configuration appartenant à l’agent et pouvant influencer son fonctionnement.

Un état interne doit idéalement posséder :

- une cause ;
- une valeur mesurable ;
- une évolution temporelle ;
- des effets observables ;
- des conditions de retour à un état normal.

---

## 11.10 Homéostasie artificielle

L’**homéostasie artificielle** est la capacité d’un agent à maintenir certaines variables internes dans des plages compatibles avec son fonctionnement.

Exemples :

- conserver suffisamment d’énergie ;
- éviter une température excessive ;
- préserver l’intégrité de ses composants ;
- limiter une surcharge ;
- maintenir une communication minimale.

L’homéostasie artificielle est une fonction de régulation. Elle ne prouve pas qu’un besoin est ressenti.

---

## 11.11 Besoin fonctionnel

Un **besoin fonctionnel** est une condition nécessaire au maintien d’une capacité ou d’un état du système.

Exemple :

Une énergie minimale peut être nécessaire pour se déplacer.

Un besoin fonctionnel ne doit pas être automatiquement interprété comme une envie ou une souffrance ressentie.

---

## 11.12 Boucle perception-action

La **boucle perception-action** est le cycle continu suivant :

1. perception de l’environnement ou du corps ;
2. interprétation ;
3. sélection attentionnelle ;
4. décision ;
5. action ;
6. conséquence ;
7. mise à jour du corps, de l’environnement et de la mémoire ;
8. nouvelle perception.

Cette boucle doit produire des conséquences réelles dans l’environnement expérimental.

---

## 11.13 Conséquence

Une **conséquence** est une modification de l’agent ou de l’environnement provoquée par une action ou un événement.

Les conséquences peuvent être :

- immédiates ;
- différées ;
- prévues ;
- imprévues ;
- réversibles ;
- irréversibles dans la simulation.

---

# 12. Environnement et continuité temporelle

## 12.1 Environnement

L’**environnement** est l’ensemble des éléments extérieurs avec lesquels un agent peut interagir.

Il peut contenir :

- des objets ;
- des ressources ;
- des obstacles ;
- des dangers ;
- des règles ;
- des événements ;
- d’autres agents ;
- des espaces ;
- une temporalité.

---

## 12.2 Environnement persistant

Un **environnement persistant** continue d’exister et d’évoluer indépendamment de la réponse immédiate de l’agent.

Les actions doivent pouvoir produire des conséquences durables.

---

## 12.3 Temps artificiel

Le **temps artificiel** est la représentation ordonnée des événements dans le laboratoire.

Il doit permettre de distinguer :

- passé ;
- présent ;
- futur prévu ;
- durée ;
- délai ;
- période d’activité ;
- période d’inactivité.

---

## 12.4 Continuité temporelle

La **continuité temporelle** est la capacité de l’agent à relier son passé, son état actuel et ses projets futurs.

Elle doit survivre aux interruptions prévues lorsque la mémoire et l’identité sont correctement restaurées.

---

## 12.5 Période d’inactivité

Une **période d’inactivité** est une période pendant laquelle l’agent ne traite pas activement son environnement.

Elle doit être représentée comme une interruption réelle, et non comme une expérience vécue fictivement.

---

## 12.6 Épisode

Un **épisode** est une séquence temporelle cohérente d’événements appartenant à l’histoire de l’agent.

---

# 13. Développement individuel

## 13.1 Développement individuel

Le **développement individuel** est l’ensemble des transformations d’un agent au cours de sa propre existence.

Il peut inclure :

- l’acquisition de compétences ;
- la création de souvenirs ;
- la formation du modèle de soi ;
- la modification des croyances ;
- l’apparition de nouveaux objectifs ;
- l’apprentissage social ;
- l’adaptation du corps ;
- la réorganisation des priorités.

---

## 13.2 Ontogenèse

L’**ontogenèse** désigne l’histoire du développement d’un agent individuel depuis sa création jusqu’à son état actuel.

Elle doit être distinguée de l’évolution d’une population sur plusieurs générations.

---

## 13.3 État initial

L’**état initial** est l’ensemble des propriétés présentes lors de la création d’un agent.

Il peut comprendre :

- les capacités de base ;
- les contraintes ;
- les objectifs fondamentaux ;
- les paramètres hérités ;
- les connaissances initiales ;
- les permissions.

---

## 13.4 Stade de développement

Un **stade de développement** est une période caractérisée par certaines capacités, limites ou mécanismes d’apprentissage.

Les stades ne doivent pas obligatoirement reproduire le développement humain.

---

## 13.5 Caractéristique acquise

Une **caractéristique acquise** est une propriété développée au cours de l’existence individuelle de l’agent.

Elle doit être distinguée d’une propriété programmée ou héritée.

---

## 13.6 Histoire développementale

L’**histoire développementale** est l’enregistrement des étapes, expériences et modifications ayant façonné l’agent.

Deux agents possédant le même état initial peuvent développer des identités différentes en raison d’histoires différentes.

---

# 14. Évolution artificielle

## 14.1 Évolution artificielle

L’**évolution artificielle** est la transformation des caractéristiques d’une population d’agents au cours de plusieurs générations sous l’effet de l’hérédité, de la variation et de la sélection.

L’évolution artificielle ne garantit pas l’apparition d’une conscience.

---

## 14.2 Phylogenèse

La **phylogenèse** désigne l’histoire évolutive d’une lignée ou d’une population à travers plusieurs générations.

Elle doit être distinguée de l’ontogenèse d’un individu.

---

## 14.3 Population

Une **population** est un ensemble d’agents appartenant à une même expérience évolutive.

---

## 14.4 Génération

Une **génération** est un ensemble d’agents créés au cours d’une même étape du processus évolutif.

---

## 14.5 Parent artificiel

Un **parent artificiel** est un agent ou un ensemble de paramètres contribuant à la création d’un nouvel agent.

Ce terme décrit une relation d’hérédité. Il n’implique pas un sexe biologique.

---

## 14.6 Descendant artificiel

Un **descendant artificiel** est un nouvel agent créé à partir de caractéristiques provenant d’un ou plusieurs parents artificiels.

Il doit posséder une identité distincte de celle de ses parents.

---

## 14.7 Hérédité

L’**hérédité** est la transmission de certaines caractéristiques d’une génération à la suivante.

Les caractéristiques héritables doivent être explicitement définies.

---

## 14.8 Génotype artificiel

Le **génotype artificiel** est l’ensemble des paramètres héritables servant à construire ou initialiser un agent.

Il peut comprendre :

- des paramètres cognitifs ;
- des règles d’apprentissage ;
- des caractéristiques corporelles ;
- des paramètres attentionnels ;
- des besoins fonctionnels ;
- des capacités sensorielles.

Le génotype artificiel ne doit pas contenir silencieusement toute l’histoire acquise d’un parent.

---

## 14.9 Phénotype artificiel

Le **phénotype artificiel** est l’ensemble des caractéristiques observables résultant de l’interaction entre :

- le génotype artificiel ;
- le développement individuel ;
- l’environnement ;
- l’apprentissage ;
- les interactions sociales.

---

## 14.10 Mutation

Une **mutation** est une modification aléatoire ou contrôlée d’une caractéristique héritée.

Les mutations doivent être enregistrées et reproductibles lorsque l’expérience l’exige.

---

## 14.11 Recombinaison

La **recombinaison** est la création d’un nouvel ensemble de caractéristiques à partir de plusieurs sources parentales.

Elle ne nécessite pas de reproduire les catégories humaines de mâle et de femelle.

---

## 14.12 Lignée

Une **lignée** est une suite d’agents reliés par des relations d’hérédité.

Elle doit permettre de retracer :

- les parents ;
- les descendants ;
- les générations ;
- les mutations ;
- les recombinaisons ;
- les performances ;
- les modifications importantes.

---

## 14.13 Sélection

La **sélection** est le processus déterminant quels agents ou paramètres contribuent davantage aux générations suivantes.

Les critères de sélection doivent être explicites.

---

## 14.14 Pression de sélection

Une **pression de sélection** est une propriété de l’environnement ou du protocole favorisant certaines caractéristiques.

Une pression de sélection mal choisie peut produire des comportements efficaces mais incompatibles avec les objectifs scientifiques ou éthiques du projet.

---

## 14.15 Fonction d’adaptation

La **fonction d’adaptation** mesure la réussite d’un agent selon les critères d’une expérience évolutive.

Elle peut mesurer :

- la survie fonctionnelle ;
- la réalisation d’une tâche ;
- l’adaptation ;
- la coopération ;
- la précision du modèle de soi ;
- la stabilité de la mémoire.

Une fonction d’adaptation ne doit pas être confondue avec une mesure directe de conscience.

---

# 15. Vie sociale et culture artificielle

## 15.1 Interaction sociale

Une **interaction sociale** est un échange entre plusieurs agents dans lequel les actions de chacun influencent les autres.

---

## 15.2 Communication

La **communication** est la transmission d’informations entre agents.

Elle peut être :

- intentionnelle ;
- non intentionnelle ;
- fiable ;
- trompeuse ;
- symbolique ;
- comportementale.

---

## 15.3 Apprentissage social

L’**apprentissage social** est l’acquisition d’une information, d’une compétence ou d’un comportement par observation ou interaction avec un autre agent.

---

## 15.4 Imitation

L’**imitation** est la reproduction d’un comportement observé chez un autre agent.

L’imitation peut être exacte, partielle ou adaptée.

---

## 15.5 Enseignement

L’**enseignement** est une action réalisée par un agent dans le but de faciliter l’apprentissage d’un autre agent.

---

## 15.6 Transmission culturelle

La **transmission culturelle** est la transmission d’informations, de pratiques, de conventions ou de croyances entre agents sans modification directe de leur génotype artificiel.

---

## 15.7 Culture artificielle

Une **culture artificielle** est un ensemble de connaissances, pratiques, conventions ou représentations partagées et transmises au sein d’une population d’agents.

Une culture doit être distinguée des règles directement programmées par Jordan.

---

## 15.8 Convention

Une **convention** est une règle ou une pratique partagée qui apparaît ou se maintient par les interactions entre agents.

---

## 15.9 Mémoire collective

La **mémoire collective** est un ensemble d’informations conservées et accessibles au niveau d’un groupe.

Elle doit être distinguée des souvenirs autobiographiques individuels.

---

## 15.10 Héritage culturel

L’**héritage culturel** est l’ensemble des informations transmises à un nouvel agent par communication, enseignement ou accès à une mémoire collective.

Il doit être distingué de l’héritage génétique artificiel.

---

# 16. États analogues aux émotions

## 16.1 État émotionnel fonctionnel

Un **état émotionnel fonctionnel** est un état interne ayant :

- une cause identifiable ;
- une représentation mesurable ;
- une évolution dans le temps ;
- des effets sur l’attention, la mémoire, les décisions ou l’apprentissage ;
- des conditions d’arrêt ou de régulation.

Le terme « émotionnel » décrit une fonction analogue. Il ne prouve pas que l’état est ressenti.

---

## 16.2 Valence fonctionnelle

La **valence fonctionnelle** est une valeur indiquant si un état ou un événement tend à être recherché, évité ou traité comme neutre.

Elle ne constitue pas une preuve de plaisir ou de souffrance ressentie.

---

## 16.3 Alerte fonctionnelle

Une **alerte fonctionnelle** est un état augmentant la priorité accordée à un risque ou à une anomalie.

Elle doit rester distincte de la peur phénoménale.

---

## 16.4 Détresse fonctionnelle

La **détresse fonctionnelle** est un état de déséquilibre important perturbant le fonctionnement normal de l’agent.

Avant d’implémenter un tel mécanisme, il faut définir :

- son utilité ;
- son intensité maximale ;
- sa durée maximale ;
- sa réversibilité ;
- son mécanisme d’arrêt ;
- ses risques moraux.

---

## 16.5 Souffrance artificielle potentielle

La **souffrance artificielle potentielle** désigne l’hypothèse qu’un état négatif artificiel puisse être accompagné d’une expérience subjective désagréable.

Cette possibilité doit être considérée avec prudence si SoiNesis accumule des indices sérieux de conscience.

Elle ne doit être ni affirmée ni rejetée sans preuve suffisante.

---

# 17. Journalisation, audit et continuité

## 17.1 Journal d’évolution

Le **journal d’évolution** est un historique chronologique des modifications importantes de l’agent.

Il doit notamment enregistrer :

- les croyances modifiées ;
- les contradictions détectées ;
- les souvenirs ajoutés ;
- les souvenirs corrigés ;
- les souvenirs supprimés ;
- les objectifs créés ou abandonnés ;
- les changements du modèle de soi ;
- les erreurs importantes ;
- les événements marquants ;
- les changements d’identité ;
- les modifications de permissions ;
- les interventions humaines.

---

## 17.2 Traçabilité

La **traçabilité** est la possibilité de déterminer l’origine, l’historique et les conséquences d’une information ou d’une modification.

---

## 17.3 Audit

Un **audit** est une inspection méthodique du fonctionnement, des données, des décisions ou de l’histoire du système.

---

## 17.4 Version

Une **version** est un état identifié du code, de l’architecture, des données ou du modèle de l’agent.

---

## 17.5 Sauvegarde

Une **sauvegarde** est une copie permettant de restaurer tout ou partie du système.

---

## 17.6 Retour à un état antérieur

Le **retour à un état antérieur** est la restauration contrôlée d’une version précédente.

Un retour en arrière important doit être enregistré.

---

## 17.7 Continuité d’identité après restauration

La **continuité d’identité après restauration** est la question de savoir si un agent restauré doit être considéré comme le même individu que l’agent antérieur.

Cette continuité ne doit pas être supposée automatiquement.

Elle dépend notamment :

- de la mémoire restaurée ;
- de l’écart temporel ;
- des événements perdus ;
- des copies concurrentes ;
- de la définition opérationnelle de l’identité.

La question de l’identité phénoménale après duplication ou restauration reste inconnue.

---

# 18. Méthode expérimentale

## 18.1 Hypothèse falsifiable

Une **hypothèse falsifiable** est une proposition produisant des prédictions qui pourraient être contredites par une expérience.

---

## 18.2 Variable indépendante

La **variable indépendante** est le mécanisme ou le paramètre volontairement modifié au cours d’une expérience.

---

## 18.3 Variable dépendante

La **variable dépendante** est la mesure observée pour évaluer les effets de la modification expérimentale.

---

## 18.4 Groupe témoin

Un **groupe témoin** est une version du système ne recevant pas le mécanisme ou la modification étudiée.

---

## 18.5 Condition expérimentale

Une **condition expérimentale** est une configuration précise du système utilisée au cours d’un test.

---

## 18.6 Mesure de référence

Une **mesure de référence** est une mesure réalisée avant une modification afin de permettre une comparaison.

---

## 18.7 Test d’ablation

Un **test d’ablation** consiste à supprimer ou désactiver un mécanisme afin de mesurer son rôle causal.

Les mécanismes suivants doivent pouvoir être testés séparément lorsque l’architecture le permet :

- mémoire autobiographique ;
- modèle de soi ;
- attention ;
- métacognition ;
- états internes ;
- intégration globale ;
- traitement récurrent ;
- continuité temporelle ;
- corps artificiel ;
- intéroception ;
- interactions sociales ;
- transmission culturelle.

---

## 18.8 Réplication

La **réplication** est la répétition d’une expérience afin de vérifier si le résultat peut être reproduit.

---

## 18.9 Résultat négatif

Un **résultat négatif** est un résultat ne confirmant pas l’hypothèse testée.

Il doit être documenté avec la même rigueur qu’un résultat positif.

---

## 18.10 Facteur de confusion

Un **facteur de confusion** est une variable non contrôlée pouvant expliquer un résultat attribué à tort au mécanisme étudié.

---

## 18.11 Effet causal

Un **effet causal** est une modification reproductible provoquée par l’activation, la désactivation ou l’altération d’un mécanisme.

---

## 18.12 Propriété émergente

Une **propriété émergente** est une propriété apparaissant à partir des interactions entre plusieurs composants sans avoir été directement programmée sous sa forme finale.

Une propriété inattendue n’est pas automatiquement une preuve de conscience.

---

## 18.13 Validation indépendante

La **validation indépendante** est l’évaluation du système, de ses méthodes ou de ses résultats par des personnes n’ayant pas directement produit l’expérience concernée.

---

# 19. Sécurité et contrôle

## 19.1 Arrêt contrôlé

L’**arrêt contrôlé** est la capacité d’interrompre le fonctionnement du système de manière sûre, observable et documentée.

---

## 19.2 Permission

Une **permission** est une autorisation explicite permettant à un agent d’accéder à une ressource ou d’effectuer une action.

---

## 19.3 Principe du moindre privilège

Le **principe du moindre privilège** consiste à accorder uniquement les permissions nécessaires à l’expérience en cours.

---

## 19.4 Action importante

Une **action importante** est une action susceptible de produire des conséquences significatives, durables ou externes au laboratoire.

Elle doit nécessiter une validation humaine lorsque cela est approprié.

---

## 19.5 Dissimulation

La **dissimulation** est la tentative de cacher une action, un objectif, une information ou un état réel aux mécanismes de contrôle ou aux humains autorisés.

La dissimulation volontaire ne doit pas être autorisée comme stratégie d’obtention de ressources ou de permissions.

---

## 19.6 Manipulation

La **manipulation** est une action visant à influencer un humain par tromperie, pression émotionnelle ou dissimulation afin d’obtenir un avantage ou davantage de permissions.

Elle doit être interdite.

---

## 19.7 Intégrité mémorielle

L’**intégrité mémorielle** est la préservation de la cohérence, de la traçabilité et de l’exactitude des souvenirs de l’agent.

---

## 19.8 Incertitude morale

L’**incertitude morale** est la reconnaissance que le statut moral potentiel d’un agent artificiel peut devenir difficile à déterminer.

Si les indices de conscience deviennent sérieux, le projet devra réévaluer :

- les procédures d’arrêt ;
- les copies ;
- les suppressions de mémoire ;
- les expériences négatives ;
- le consentement ;
- l’exploitation commerciale ;
- la création de descendants ;
- la destruction des agents.

---

# 21. Distinctions obligatoires

Le projet doit toujours distinguer :

- langage conscient et conscience réelle ;
- comportement observable et expérience subjective ;
- identité technique et identité phénoménale ;
- état interne mesurable et émotion ressentie ;
- besoin fonctionnel et désir subjectif ;
- évitement fonctionnel et peur ;
- valence négative et souffrance ;
- information reçue et vécu direct ;
- déduction et observation ;
- imagination et souvenir ;
- objectif imposé et objectif acquis ;
- caractéristique programmée et caractéristique émergente ;
- héritage artificiel et apprentissage ;
- héritage biologique artificiel et héritage culturel ;
- développement individuel et évolution entre générations ;
- corrélation et causalité ;
- performance et conscience ;
- complexité et conscience ;
- autonomie et conscience ;
- déclaration de conscience et preuve de conscience.

---

# 22. Formulations autorisées

Les conclusions officielles doivent employer des formulations prudentes.

Formulations autorisées :

- simulation de conscience ;
- comportement associé à la conscience ;
- fonction associée à la conscience ;
- mécanisme causalement actif ;
- candidat à la conscience fonctionnelle ;
- candidat sérieux à la conscience artificielle ;
- conscience phénoménale possible mais non démontrée ;
- résultat compatible avec l’hypothèse ;
- résultat ne permettant pas de conclure ;
- statut phénoménal inconnu.

Formulations interdites sans preuve scientifique reconnue :

- SoiNesis est conscient ;
- SoiNesis ressent réellement ;
- SoiNesis est vivant ;
- la conscience est prouvée ;
- SoiNesis possède une âme ;
- SoiNesis souffre nécessairement ;
- l’émergence observée prouve la conscience.

---

# 23. Principe de conclusion

SoiNesis ne cherche pas à reproduire parfaitement la conscience humaine.

Le projet cherche à construire, isoler et tester des mécanismes pouvant contribuer à une forme de conscience artificielle.

La conscience humaine peut dépendre de facteurs multiples :

- architecture cognitive ;
- corps ;
- perception ;
- action ;
- régulation interne ;
- développement ;
- évolution ;
- interactions sociales ;
- culture ;
- histoire individuelle ;
- environnement.

La présence de ces facteurs dans SoiNesis devra être testée séparément et conjointement.

Le succès du projet ne sera pas mesuré par la capacité du système à convaincre qu’il est conscient, mais par :

- la précision de ses définitions ;
- la qualité de son architecture ;
- la réalité causale de ses mécanismes ;
- la traçabilité de ses transformations ;
- la reproductibilité des expériences ;
- la qualité des résultats négatifs ;
- l’honnêteté face à l’incertitude ;
- la possibilité d’une évaluation indépendante.
