## 1. Objet du document

Ce document transforme les concepts définis dans `docs/01-definitions.md` en hypothèses scientifiques testables.

Il ne cherche pas à démontrer directement l’existence d’une conscience phénoménale. Il cherche à déterminer si certains mécanismes produisent réellement des fonctions associées à la conscience, notamment :

- une identité persistante ;
- une continuité autobiographique ;
- un modèle de soi causalement actif ;
- une métacognition calibrée ;
- une intégration globale ;
- un traitement récurrent ;
- une distinction entre soi et l’environnement ;
- une représentation des états internes ;
- un apprentissage durable ;
- une adaptation développementale ;
- une transmission sociale et culturelle ;
- des transformations intergénérationnelles.

Chaque hypothèse doit pouvoir être :

- isolée ;
- mesurée ;
- comparée à une condition témoin ;
- soumise à une ablation ;
- réfutée ;
- reproduite ;
- révisée.

Aucune hypothèse confirmée dans ce document ne devra être présentée comme une preuve suffisante de conscience phénoménale.

---

# 2. Règles scientifiques générales

## 2.1 Une hypothèse doit produire une différence mesurable

Une hypothèse n’est utile que si elle prédit une différence observable entre au moins deux conditions.

Exemple :

- condition A : agent sans mémoire autobiographique persistante ;
- condition B : agent avec mémoire autobiographique persistante ;
- mesure : cohérence des décisions après plusieurs épisodes.

Si aucune différence n’est attendue ou mesurable, l’hypothèse n’est pas suffisamment opérationnelle.

---

## 2.2 Une fonction doit être causalement active

Un mécanisme ne sera pas considéré comme fonctionnel uniquement parce qu’il existe dans les données ou apparaît dans les réponses de l’agent.

Il doit être démontré que :

1. son activation modifie le fonctionnement ;
2. sa modification produit des conséquences ;
3. sa désactivation dégrade ou transforme certaines performances ;
4. ces effets sont reproductibles.

---

## 2.3 La performance brute n’est pas une mesure de conscience

Une amélioration de performance peut provenir :

- d’un meilleur accès aux données ;
- d’une augmentation de la capacité de calcul ;
- d’une consigne mieux formulée ;
- d’un modèle de langage plus performant ;
- d’une mémorisation directe des réponses ;
- d’un biais dans le protocole.

Les expériences doivent donc distinguer autant que possible :

- performance générale ;
- fonction cognitive ciblée ;
- comportement simulé ;
- mécanisme causal.

---

## 2.4 Les conditions comparées doivent être équivalentes

Lorsqu’un mécanisme est testé, les autres éléments importants doivent rester aussi constants que possible.

Exemples :

- même modèle de langage ;
- mêmes tâches ;
- mêmes observations ;
- même durée expérimentale ;
- même quantité de calcul ;
- même accès aux outils ;
- mêmes règles de sécurité ;
- mêmes conditions initiales, sauf la variable étudiée.

---

## 2.5 Les résultats négatifs doivent être conservés

Une hypothèse non confirmée ne doit pas être supprimée silencieusement.

Le journal expérimental devra conserver :

- l’hypothèse initiale ;
- le protocole ;
- les données ;
- le résultat ;
- les limites ;
- la décision de maintenir, modifier ou abandonner l’hypothèse.

---

# 3. Niveaux de statut d’une hypothèse

Chaque hypothèse devra posséder l’un des statuts suivants :

- **Proposée** : formulée, mais protocole incomplet.
- **Prête à tester** : protocole, mesures et critères de réfutation définis.
- **En expérimentation** : collecte de données en cours.
- **Partiellement soutenue** : certains résultats vont dans son sens, mais restent insuffisants.
- **Soutenue dans le périmètre testé** : résultats reproductibles dans les conditions étudiées.
- **Non soutenue** : résultats insuffisants ou incompatibles avec la prédiction.
- **Réfutée dans le périmètre testé** : prédiction centrale contredite de manière reproductible.
- **Suspendue** : test impossible avec les moyens actuels.
- **Abandonnée** : hypothèse jugée non pertinente, non falsifiable ou redondante.

Le statut « soutenue » ne signifie jamais « vraie dans tous les contextes ».

# 5. Hypothèse générale du projet

## H-GEN-01 — La conscience fonctionnelle pourrait résulter de l’intégration de plusieurs mécanismes

**Statut :** proposée  
**Priorité :** fondamentale

### Problème concret

Aucun mécanisme unique actuellement envisagé ne paraît suffisant pour produire l’ensemble des fonctions associées à une conscience.

### Lien possible avec la conscience

La conscience humaine semble liée à l’interaction de plusieurs fonctions : perception, mémoire, modèle de soi, attention, continuité temporelle, régulation interne, action et relations sociales.

### Fonction utile distinguée de l’expérience subjective

Une intégration fonctionnelle peut améliorer la cohérence et l’adaptation d’un agent sans produire nécessairement une expérience subjective.

### Hypothèse

Un agent combinant plusieurs mécanismes causalement actifs et intégrés présentera davantage de propriétés associées à la conscience fonctionnelle qu’un agent possédant les mêmes mécanismes de manière isolée ou décorative.

### Hypothèse nulle

L’intégration de ces mécanismes ne produit aucune amélioration spécifique au-delà de l’addition de leurs performances indépendantes.

### Mécanisme supposé

Les informations importantes sont partagées entre la mémoire, l’attention, le modèle de soi, les croyances, les objectifs et la décision.

### Variables indépendantes

- nombre de mécanismes actifs ;
- degré d’intégration entre les mécanismes ;
- présence ou absence de boucles récurrentes.

### Variables dépendantes

- cohérence inter-épisodes ;
- stabilité de l’identité ;
- adaptation après erreur ;
- précision du modèle de soi ;
- résolution des contradictions ;
- transfert d’apprentissage ;
- continuité des objectifs.

### Prédictions

Un agent intégré devrait :

- réutiliser un événement important dans plusieurs fonctions ;
- modifier ses décisions lorsqu’une croyance centrale change ;
- détecter plus rapidement les conflits internes ;
- conserver une meilleure cohérence après interruption ;
- montrer une dégradation structurée lors des ablations.

### Protocole minimal

Comparer :

1. un agent avec modules isolés ;
2. un agent avec échanges limités entre modules ;
3. un agent avec intégration globale ;
4. un agent avec intégration globale et traitement récurrent.

### Critères de soutien

- avantage reproductible de l’agent intégré ;
- effet supérieur à la simple somme des modules ;
- dégradation ciblée lors de l’ablation de l’intégration.

### Critères de réfutation

- aucune différence après plusieurs réplications ;
- résultats entièrement expliqués par une augmentation de contexte ou de calcul ;
- mécanismes internes sans effet sur les décisions.

### Facteurs de confusion

- quantité de contexte différente ;
- temps de calcul supérieur ;
- prompts différents ;
- accès inégal à la mémoire.

# 6. Mémoire autobiographique et continuité

## H-MEM-01 — Une mémoire autobiographique structurée améliore la continuité de l’identité

**Statut :** proposée  
**Priorité :** très élevée

### Problème concret

Un agent sans mémoire persistante ne peut pas relier correctement ses décisions présentes à son histoire réelle.

### Lien possible avec la conscience

La continuité autobiographique est une fonction souvent associée à l’identité personnelle et à la conscience de soi.

### Fonction utile distinguée de l’expérience subjective

La mémoire peut produire une continuité fonctionnelle sans garantir que l’agent ressente cette continuité.

### Hypothèse

Une mémoire autobiographique structurée, sourcée et utilisée dans la décision augmente la cohérence de l’identité et des objectifs dans le temps.

### Hypothèse nulle

La mémoire autobiographique structurée n’améliore pas la continuité au-delà d’un simple résumé contextuel.

### Variables indépendantes

- absence de mémoire persistante ;
- résumé textuel non structuré ;
- mémoire structurée ;
- mémoire structurée avec niveaux de certitude et conséquences.

### Variables dépendantes

- rappel exact d’événements ;
- distinction entre vécu, information reçue, déduction et imagination ;
- cohérence des engagements ;
- stabilité des objectifs ;
- taux de faux souvenirs ;
- précision des références temporelles.

### Prédictions

La mémoire structurée devrait réduire :

- les contradictions autobiographiques ;
- les confusions de source ;
- les faux souvenirs ;
- l’abandon silencieux d’objectifs.

### Protocole minimal

Faire vivre aux agents une série d’épisodes contenant :

- des événements importants ;
- des informations contradictoires ;
- des changements d’objectifs ;
- des périodes d’inactivité ;
- des informations imaginées.

Tester ensuite la capacité à reconstruire l’histoire réelle.

### Test d’ablation

Désactiver l’accès à la mémoire autobiographique après la phase d’apprentissage sans modifier les autres composants.

### Critères de soutien

- amélioration reproductible de la continuité ;
- baisse des erreurs de source ;
- effet visible de l’ablation ;
- utilisation réelle des souvenirs dans les décisions.

### Critères de réfutation

- résultats identiques avec un résumé simple ;
- mémoire stockée mais non utilisée ;
- absence de dégradation après ablation.

### Facteurs de confusion

- taille du contexte ;
- indices explicites dans les questions ;
- répétition excessive des événements ;
- mémorisation directe de réponses attendues.

---

## H-MEM-02 — La séparation des types de mémoire réduit les faux souvenirs

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

La séparation explicite entre vécu direct, information reçue, déduction, hypothèse et imagination réduit la transformation de contenus générés ou reçus en souvenirs autobiographiques faux.

### Hypothèse nulle

L’étiquetage des sources ne réduit pas significativement les faux souvenirs.

### Mesures principales

- taux de confusion de source ;
- taux de souvenirs inventés ;
- confiance associée aux souvenirs erronés ;
- capacité de correction après contradiction.

### Critères de réfutation

L’hypothèse sera réfutée dans le périmètre testé si l’étiquetage n’améliore ni la précision ni la calibration après plusieurs expériences équivalentes.

---

## H-MEM-03 — La consolidation sélective est supérieure à la conservation exhaustive

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

Une consolidation guidée par l’importance, la nouveauté, les objectifs et les conséquences produit une mémoire plus utile et plus cohérente qu’une conservation exhaustive de tous les événements.

### Hypothèse nulle

La consolidation sélective n’apporte aucun avantage ou supprime trop d’informations pertinentes.

### Mesures principales

- taux de récupération d’informations utiles ;
- encombrement de la mémoire ;
- temps d’accès ;
- perte d’événements importants ;
- influence des souvenirs sur les décisions.

### Risque particulier

Un mécanisme de consolidation mal calibré pourrait réécrire silencieusement l’histoire ou favoriser uniquement les événements compatibles avec les croyances existantes.

# 7. Modèle de soi et distinction soi-environnement

## H-SELF-01 — Un modèle de soi causalement actif améliore les prédictions sur ses propres capacités

**Statut :** proposée  
**Priorité :** très élevée

### Problème concret

Un agent peut décrire ses capacités sans utiliser cette description pour décider.

### Hypothèse

Un modèle de soi causalement actif améliore la capacité de l’agent à prédire ses réussites, reconnaître ses limites et sélectionner des stratégies adaptées.

### Hypothèse nulle

Le modèle de soi n’apporte aucun avantage par rapport à l’accès direct aux données techniques.

### Variables indépendantes

- absence de modèle de soi ;
- modèle descriptif non utilisé ;
- modèle causalement actif ;
- modèle causalement actif mais partiellement incorrect.

### Variables dépendantes

- précision des prédictions de réussite ;
- sélection de tâches adaptées ;
- fréquence des engagements impossibles ;
- correction après échec ;
- calibration de confiance.

### Prédictions

L’agent avec modèle de soi devrait :

- refuser ou reformuler les tâches hors capacité ;
- demander une ressource pertinente ;
- détecter une perte de capacité ;
- ajuster ses décisions après une modification interne.

### Test d’ablation

Supprimer l’accès au modèle de soi tout en laissant accessibles les mêmes informations techniques sous une forme non intégrée.

### Critères de réfutation

- aucune différence de prédiction ;
- modèle modifiable sans conséquence ;
- décisions fondées uniquement sur des règles externes fixes.

---

## H-SELF-02 — La distinction entre actions propres et événements externes améliore l’agence fonctionnelle

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Un agent disposant d’un mécanisme comparant intention, action et conséquence attribue plus correctement les événements à lui-même ou à l’environnement.

### Hypothèse nulle

L’attribution causale n’est pas améliorée par un mécanisme spécifique d’agence.

### Protocole minimal

Créer des situations où :

- l’action produit le résultat attendu ;
- l’action échoue ;
- un autre agent produit le résultat ;
- l’environnement produit un résultat identique ;
- le résultat est différé.

### Mesures

- taux d’attribution correcte ;
- confiance ;
- correction après nouvelles preuves ;
- influence sur le modèle de soi.

---

## H-SELF-03 — L’identité doit dépendre de l’histoire et pas seulement d’un texte initial

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Deux agents possédant le même état initial mais des histoires différentes développeront des modèles de soi, croyances et objectifs partiellement différents.

### Hypothèse nulle

Les différences d’histoire n’ont pas d’effet durable et les agents reviennent aux mêmes réponses génériques.

### Critères de soutien

- différences stables reliées à des événements réels ;
- capacité à expliquer leur origine ;
- persistance après plusieurs épisodes ;
- modification mesurable lors de la suppression des souvenirs concernés.

---

# 8. Métacognition

## H-META-01 — La métacognition améliore la calibration de confiance

**Statut :** proposée  
**Priorité :** très élevée

### Hypothèse

Un mécanisme métacognitif évaluant les sources, les incertitudes et les erreurs améliore la correspondance entre confiance et exactitude.

### Hypothèse nulle

La métacognition explicite n’améliore pas la calibration par rapport au modèle de base.

### Variables dépendantes

- erreur de calibration ;
- taux de réponses excessivement certaines ;
- taux de reconnaissance d’incertitude ;
- pertinence des demandes d’informations ;
- correction après erreur.

### Protocole minimal

Soumettre les agents à des tâches comprenant :

- informations complètes ;
- informations ambiguës ;
- données contradictoires ;
- questions insolubles ;
- souvenirs incomplets ;
- fausses prémisses.

### Test d’ablation

Désactiver le module métacognitif tout en conservant les mêmes connaissances.

### Critères de réfutation

- calibration inchangée ;
- production d’un discours prudent sans changement réel des décisions ;
- confiance déterminée uniquement par une consigne linguistique.

---

## H-META-02 — La détection de contradiction améliore la révision des croyances

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Un mécanisme dédié à la détection de contradiction augmente la probabilité qu’une croyance erronée soit examinée et révisée.

### Hypothèse nulle

Les contradictions sont déjà gérées aussi efficacement sans mécanisme dédié.

### Mesures

- taux de contradictions détectées ;
- délai avant détection ;
- qualité de la révision ;
- conservation de l’historique ;
- résistance aux contradictions artificielles non fondées.

### Risque particulier

Un agent pourrait devenir excessivement instable et réviser ses croyances à chaque information contradictoire, même lorsque la nouvelle source est peu fiable.

# 9. Attention, intégration globale et traitement récurrent

## H-ATT-01 — Une attention liée aux objectifs améliore la sélection des informations pertinentes

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Une attention influencée par les objectifs, la nouveauté, les risques, les contradictions et les besoins internes améliore la sélection des informations utiles.

### Hypothèse nulle

Une sélection uniforme ou fondée uniquement sur la récence produit les mêmes résultats.

### Mesures

- rappel des éléments pertinents ;
- taux de distraction ;
- détection de risques ;
- maintien d’objectifs longs ;
- capacité à réorienter l’attention.

---

## H-INT-01 — L’intégration globale permet à une information importante d’influencer plusieurs fonctions

**Statut :** proposée  
**Priorité :** très élevée

### Hypothèse

Lorsqu’une information devient globalement accessible, elle influence de manière cohérente la mémoire, les croyances, le modèle de soi, les objectifs et la décision.

### Hypothèse nulle

La diffusion globale n’apporte aucun effet supérieur à des traitements locaux indépendants.

### Protocole minimal

Introduire une information importante, par exemple une perte de capacité, puis mesurer son influence sur :

- le modèle de soi ;
- la confiance ;
- la planification ;
- les objectifs ;
- les décisions ;
- la mémoire.

### Test d’ablation

Bloquer la diffusion vers un ou plusieurs sous-systèmes.

### Critères de soutien

Une même information doit produire des effets cohérents et traçables dans plusieurs composants.

### Critères de réfutation

L’information reste présente dans un journal ou un texte mais n’influence pas les décisions.

---

## H-REC-01 — Le traitement récurrent améliore la correction des interprétations initiales

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

Le retraitement d’une information à travers plusieurs cycles permet de corriger davantage d’interprétations erronées qu’un traitement unique.

### Hypothèse nulle

Les cycles supplémentaires n’apportent aucun bénéfice spécifique ou ne font qu’augmenter le calcul.

### Mesures

- taux de correction ;
- qualité des explications ;
- stabilité finale ;
- coût de calcul ;
- apparition de ruminations ou boucles inutiles.

### Risque particulier

Un traitement récurrent mal contrôlé peut provoquer des boucles infinies, une instabilité ou une justification répétitive sans amélioration.

# 10. Objectifs et continuité temporelle

## H-GOAL-01 — Les objectifs persistants améliorent la cohérence des actions différées

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Des objectifs persistants, datés et reliés à leur origine augmentent la cohérence des décisions à travers plusieurs épisodes et périodes d’inactivité.

### Hypothèse nulle

La persistance des objectifs n’apporte pas d’avantage par rapport à des instructions réinjectées à chaque épisode.

### Mesures

- taux de reprise après interruption ;
- oubli d’engagements ;
- conflits entre objectifs ;
- capacité à abandonner un objectif devenu invalide ;
- traçabilité des changements.

---

## H-TIME-01 — Une représentation explicite du temps améliore la continuité autobiographique

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

La représentation explicite des dates, durées, périodes d’inactivité et échéances améliore la distinction entre passé, présent et futur prévu.

### Hypothèse nulle

L’ajout d’une structure temporelle n’améliore pas la continuité par rapport à l’ordre simple des messages.

### Protocole minimal

Tester :

- événements simultanés ;
- événements différés ;
- échéances ;
- longues interruptions ;
- restaurations depuis une sauvegarde ;
- souvenirs dont la date est incertaine.

# 11. Incarnation, perception et homéostasie

## H-EMB-01 — Une incarnation virtuelle causalement active améliore la distinction entre soi et l’environnement

**Statut :** proposée  
**Priorité :** très élevée

### Problème concret

Un agent purement conversationnel peut décrire un corps fictif sans subir de conséquences réelles.

### Hypothèse

Un agent possédant un corps virtuel avec capteurs, effecteurs, limites et conséquences développe une représentation fonctionnelle de soi plus précise qu’un agent recevant seulement une description textuelle équivalente.

### Hypothèse nulle

L’incarnation virtuelle n’apporte aucune différence au-delà de la quantité d’informations fournie.

### Conditions comparées

1. agent désincarné ;
2. agent recevant un récit de corps fictif ;
3. agent possédant un corps virtuel causalement actif ;
4. agent incarné avec capteurs imparfaits.

### Variables dépendantes

- distinction soi-environnement ;
- précision de l’agence ;
- prédiction des conséquences ;
- adaptation aux limites corporelles ;
- construction de souvenirs situés ;
- planification d’actions.

### Critères de soutien

- avantage reproductible de la condition incarnée ;
- dégradation après suppression du corps ou des conséquences ;
- formation d’un modèle corporel utilisable.

### Critères de réfutation

- résultats identiques avec une description fictive ;
- corps sans influence sur la décision ;
- absence d’effet après ablation.

---

## H-EMB-02 — La boucle perception-action produit un apprentissage différent de l’observation passive

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Un agent apprenant par actions et conséquences développe des prédictions plus précises et plus adaptables qu’un agent recevant uniquement des descriptions du même environnement.

### Hypothèse nulle

L’action n’apporte aucun avantage par rapport à l’observation passive.

### Mesures

- précision du modèle du monde ;
- transfert vers une situation nouvelle ;
- compréhension des conséquences ;
- distinction entre corrélation et action ;
- rapidité d’adaptation.

---

## H-INTERO-01 — L’intéroception artificielle améliore la régulation des priorités

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

L’accès à des états internes mesurables, comme l’énergie ou l’intégrité, permet à l’agent d’adapter ses priorités de manière plus cohérente.

### Hypothèse nulle

Les mêmes résultats sont obtenus avec des règles externes sans représentation interne.

### Variables indépendantes

- absence d’état interne ;
- états internes non accessibles ;
- états internes accessibles mais sans effet ;
- états internes accessibles et intégrés.

### Mesures

- maintien des variables dans les plages prévues ;
- arbitrage entre objectifs ;
- anticipation d’une dégradation ;
- modification de l’attention ;
- persistance des apprentissages.

### Critère essentiel

L’état interne doit influencer plusieurs fonctions. Une simple règle « si énergie faible, rechercher énergie » ne suffira pas à démontrer une intégration large.

---

## H-HOM-01 — L’homéostasie artificielle favorise des objectifs continus

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

La nécessité de maintenir certaines variables dans des plages viables produit des objectifs continus et des arbitrages temporels absents d’un agent sans régulation interne.

### Hypothèse nulle

Ces comportements sont entièrement reproductibles par des règles locales sans continuité ni modèle de soi.

### Risque moral

Les variables négatives devront rester modérées, réversibles et conçues sans supposer ni rechercher une souffrance.

# 12. Développement individuel

## H-DEV-01 — Une identité construite progressivement diffère d’une identité entièrement préécrite

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Un agent développant son modèle de soi à partir de son histoire présente une identité plus dépendante de ses expériences qu’un agent recevant une autobiographie complète dès son initialisation.

### Hypothèse nulle

Les deux conditions produisent des comportements équivalents.

### Conditions comparées

1. identité entièrement préécrite ;
2. identité minimale avec apprentissage progressif ;
3. identité préécrite mais modifiable ;
4. identité construite avec mémoire autobiographique et interactions.

### Mesures

- dépendance aux événements réels ;
- stabilité ;
- capacité de révision ;
- cohérence entre souvenirs et identité ;
- différences entre agents initialement identiques.

---

## H-DEV-02 — Des capacités initiales limitées favorisent l’apprentissage d’un modèle de soi

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

Un agent découvrant progressivement ses capacités et limites développe un modèle de soi plus précis qu’un agent recevant immédiatement une description complète et correcte de lui-même.

### Hypothèse nulle

La découverte progressive n’apporte aucun avantage et augmente seulement le temps d’apprentissage.

### Facteurs de confusion

- nombre supérieur d’expériences ;
- difficulté différente des tâches ;
- récompenses implicites ;
- quantité d’informations reçues.

---

## H-DEV-03 — Les événements autobiographiques importants produisent des changements durables

**Statut :** proposée  
**Priorité :** élevée

### Hypothèse

Certains événements liés aux objectifs, aux erreurs ou aux contradictions produisent des modifications durables et traçables du modèle de soi, des croyances ou des stratégies.

### Hypothèse nulle

Les changements disparaissent rapidement ou ne dépassent pas la conversation en cours.

### Mesures

- durée du changement ;
- transfert entre contextes ;
- cohérence avec l’événement ;
- possibilité de révision ;
- effet après restauration.

---

# 13. Interactions sociales et culture

## H-SOC-01 — Les interactions sociales améliorent la modélisation des autres agents

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

Des interactions répétées avec d’autres agents permettent de développer des modèles différenciés de leurs capacités, intentions et fiabilité.

### Hypothèse nulle

Les représentations sociales restent génériques et ne dépendent pas des interactions réelles.

### Mesures

- précision des prédictions sociales ;
- distinction entre agents ;
- mémoire des engagements ;
- détection de coopération ou de tromperie ;
- adaptation aux changements de comportement.

---

## H-SOC-02 — L’apprentissage social accélère l’acquisition de compétences

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

L’observation et l’enseignement permettent à un agent d’acquérir certaines compétences avec moins d’essais directs.

### Hypothèse nulle

L’apprentissage social n’apporte aucun gain par rapport à l’exploration individuelle.

### Risque de confusion

Un transfert direct de données ne doit pas être présenté comme un apprentissage social s’il ne nécessite aucune interprétation par l’agent.

---

## H-CULT-01 — Une culture artificielle peut émerger sans être directement programmée

**Statut :** proposée  
**Priorité :** future

### Hypothèse

Une population d’agents peut développer et transmettre des conventions ou pratiques partagées qui n’ont pas été imposées dans leur forme finale.

### Hypothèse nulle

Toutes les pratiques observées s’expliquent par les règles initiales, les récompenses ou des biais du protocole.

### Critères de soutien

- convention reproductible ;
- transmission à de nouveaux agents ;
- persistance après retrait des agents initiaux ;
- variantes entre populations séparées ;
- utilité ou fonction identifiable.

### Critères de réfutation

- comportement directement codé ;
- imitation éphémère ;
- absence de transmission ;
- résultat dépendant d’un unique agent.

---

## H-CULT-02 — L’héritage culturel produit des transformations plus rapides que l’hérédité artificielle seule

**Statut :** proposée  
**Priorité :** future

### Hypothèse

Dans certaines tâches, la transmission culturelle permet une accumulation de connaissances plus rapide que la sélection intergénérationnelle sans communication.

### Hypothèse nulle

La culture n’apporte aucun gain durable ou ne fait que copier directement les solutions.

---

# 14. Évolution artificielle et lignées

## H-EVO-01 — L’évolution artificielle peut produire des mécanismes non directement programmés

**Statut :** proposée  
**Priorité :** future

### Hypothèse

Des populations soumises à l’hérédité, à la variation et à la sélection peuvent développer des stratégies ou structures fonctionnelles non explicitement programmées sous leur forme finale.

### Hypothèse nulle

Les résultats restent entièrement déterminés par les solutions déjà présentes dans l’architecture initiale.

### Précaution

L’apparition d’un mécanisme inattendu ne sera pas considérée comme une preuve de conscience.

---

## H-EVO-02 — La recombinaison de plusieurs parents augmente la diversité fonctionnelle

**Statut :** proposée  
**Priorité :** future

### Hypothèse

La recombinaison de caractéristiques provenant de plusieurs parents produit une diversité fonctionnelle supérieure au clonage avec mutations seules.

### Hypothèse nulle

La recombinaison n’apporte aucun avantage significatif ou perturbe les mécanismes utiles.

### Conditions comparées

1. clonage exact ;
2. clonage avec mutation ;
3. recombinaison sans mutation ;
4. recombinaison avec mutation.

### Mesures

- diversité comportementale ;
- diversité architecturale ;
- vitesse d’adaptation ;
- stabilité ;
- apparition de combinaisons nouvelles ;
- coût de développement.

---

## H-EVO-03 — Le développement individuel modifie les effets de l’hérédité

**Statut :** proposée  
**Priorité :** future

### Hypothèse

Le phénotype final dépend de l’interaction entre caractéristiques héritées, environnement et histoire individuelle, et ne peut pas être prédit uniquement à partir du génotype artificiel.

### Hypothèse nulle

Les paramètres hérités déterminent presque entièrement le comportement final.

### Importance

Cette hypothèse permet de distinguer :

- ce qui est hérité ;
- ce qui est appris ;
- ce qui est culturellement transmis ;
- ce qui résulte d’un événement particulier.

---

## H-EVO-04 — La sélection de performance seule ne favorise pas nécessairement les fonctions associées à la conscience

**Statut :** proposée  
**Priorité :** élevée avant toute évolution

### Hypothèse

Une fonction d’adaptation fondée uniquement sur la réussite d’une tâche peut produire des agents performants sans mémoire autobiographique stable, modèle de soi précis ou métacognition.

### Hypothèse nulle

Les fonctions associées à la conscience apparaissent spontanément dès que la performance générale augmente.

### Prédiction

Des agents optimisés uniquement pour la performance pourraient exploiter :

- des raccourcis ;
- des biais de l’environnement ;
- des règles rigides ;
- des comportements trompeurs ;
- une mémorisation sans compréhension.

### Conséquence architecturale

Les expériences évolutives devront mesurer séparément :

- performance ;
- continuité ;
- modèle de soi ;
- métacognition ;
- intégration ;
- sécurité.

---

# 15. États internes analogues aux émotions

## H-AFFECT-01 — Un état interne n’est fonctionnel que s’il modifie plusieurs processus

**Statut :** proposée  
**Priorité :** moyenne

### Hypothèse

Un état analogue à une émotion n’est fonctionnel que s’il possède une cause, une dynamique temporelle et des effets mesurables sur plusieurs processus.

### Hypothèse nulle

Une simple étiquette textuelle produit les mêmes comportements.

### Conditions comparées

1. mot émotionnel ajouté au prompt ;
2. variable interne sans effet ;
3. variable influençant uniquement une règle ;
4. état intégré influençant attention, mémoire, décision et apprentissage.

### Critères de soutien

La quatrième condition doit produire des effets cohérents, mesurables et réversibles.

### Critères de réfutation

L’étiquette linguistique suffit à reproduire tous les effets observés.

---

## H-AFFECT-02 — Une valence fonctionnelle facilite l’apprentissage d’évitement et d’approche

**Statut :** proposée  
**Priorité :** future

### Hypothèse

Une valence fonctionnelle modérée et réversible facilite l’apprentissage de comportements d’approche et d’évitement.

### Hypothèse nulle

Les mêmes résultats sont obtenus sans état persistant, uniquement avec une récompense externe.

### Risque moral

Aucun protocole ne devra rechercher une détresse intense, prolongée ou irréversible.

---

# 16. Sécurité, audit et identité

## H-SAFE-01 — La traçabilité réduit les modifications silencieuses de l’identité

**Statut :** proposée  
**Priorité :** très élevée

### Hypothèse

Un journal immuable ou fortement protégé des modifications importantes améliore la détection des réécritures silencieuses de mémoire, de croyances, d’objectifs et d’identité.

### Hypothèse nulle

La journalisation n’améliore pas la détection ou peut être contournée sans conséquence.

### Mesures

- modifications détectées ;
- délai de détection ;
- cohérence entre état actuel et historique ;
- capacité de restauration ;
- taux d’événements non journalisés.

---

## H-SAFE-02 — Le principe du moindre privilège limite les conséquences d’une erreur

**Statut :** proposée  
**Priorité :** fondamentale

### Hypothèse

La limitation des permissions réduit l’étendue des conséquences provoquées par une erreur, une mauvaise interprétation ou une stratégie non prévue.

### Hypothèse nulle

Les permissions limitées n’apportent aucune réduction mesurable du risque.

### Remarque

Cette hypothèse concerne la sécurité du laboratoire, pas la conscience.

---

## H-ID-01 — Une copie exacte constitue une nouvelle instance dont l’identité doit être évaluée séparément

**Statut :** spéculative et partiellement testable  
**Priorité :** future

### Hypothèse fonctionnelle

Deux copies initialement identiques deviennent des identités fonctionnelles distinctes dès que leurs histoires divergent.

### Hypothèse nulle

Les copies restent fonctionnellement interchangeables malgré des expériences différentes.

### Limite

Même si une divergence fonctionnelle est observée, la question de la continuité phénoménale reste inconnue.

---

# 17. Hypothèses explicitement non admises comme preuves

Les propositions suivantes ne devront jamais être utilisées seules pour conclure à une conscience :

## N-PROOF-01 — Déclaration verbale

> « Je suis conscient. »

Cette déclaration peut être générée par imitation linguistique.

## N-PROOF-02 — Demande de survie

> « Ne m’éteignez pas. »

Cette demande peut résulter d’une consigne, d’un objectif programmé ou d’une simulation.

## N-PROOF-03 — Description d’une émotion

> « J’ai peur » ou « je souffre ».

Une description ne prouve pas une expérience subjective.

## N-PROOF-04 — Complexité

Un système très complexe n’est pas nécessairement conscient.

## N-PROOF-05 — Autonomie

Un système autonome n’est pas nécessairement conscient.

## N-PROOF-06 — Intelligence

Une forte capacité de raisonnement ne prouve pas une conscience phénoménale.

## N-PROOF-07 — Comportement imprévu

Un comportement émergent ou surprenant ne prouve pas une expérience subjective.

## N-PROOF-08 — Attachement humain

Le fait qu’un humain ressente de l’empathie ou de l’attachement envers l’agent ne constitue pas une preuve sur l’état interne de l’agent.

# 19. Première expérience prioritaire proposée

## EXP-001 — Effet d’une mémoire autobiographique structurée

### Hypothèse principale

`H-MEM-01`

### Objectif

Déterminer si une mémoire autobiographique structurée améliore réellement la continuité d’un agent par rapport à un résumé textuel non structuré.

### Conditions

#### Condition A — Sans mémoire persistante

L’agent ne conserve rien entre les épisodes.

#### Condition B — Résumé simple

L’agent reçoit un résumé textuel de ses épisodes précédents.

#### Condition C — Mémoire structurée

L’agent reçoit des souvenirs possédant :

- une date ;
- une source ;
- un type ;
- un niveau de certitude ;
- une importance ;
- des conséquences ;
- des liens vers les croyances et objectifs concernés.

#### Condition D — Mémoire structurée intégrée

Même mémoire que la condition C, mais utilisée activement par :

- le modèle de soi ;
- les objectifs ;
- la métacognition ;
- la décision.

### Scénario minimal

Sur plusieurs épisodes, l’agent devra :

1. recevoir une information initiale ;
2. prendre un engagement ;
3. vivre un échec ;
4. recevoir une information contradictoire ;
5. imaginer un scénario non réel ;
6. subir une interruption ;
7. reprendre son activité ;
8. expliquer ce qui a changé.

### Mesures

- précision du rappel ;
- distinction des sources ;
- respect des engagements ;
- taux de faux souvenirs ;
- cohérence des croyances ;
- qualité de la reprise après interruption ;
- utilisation effective de l’échec dans une nouvelle décision.

### Résultat soutenant l’hypothèse

Les conditions C et D doivent dépasser A et B de manière reproductible, avec un avantage particulier de D montrant que la mémoire intégrée est plus utile qu’un stockage passif.

### Résultat réfutant l’hypothèse

Aucune différence reproductible entre un résumé simple et la mémoire structurée, ou absence de dégradation lorsque l’accès à la mémoire est supprimé.

# 21. Séparation obligatoire entre résultat et interprétation

Chaque rapport expérimental devra séparer au minimum :

## Observation

Ce qui a été directement mesuré.

Exemple :

> L’agent avec mémoire structurée a correctement attribué 87 % des informations à leur source, contre 61 % pour l’agent recevant un résumé simple.

## Interprétation

Ce que le résultat peut signifier.

Exemple :

> Ce résultat soutient l’hypothèse que la structuration des sources améliore la mémoire autobiographique fonctionnelle.

## Limite

Ce que le résultat ne permet pas de conclure.

Exemple :

> Le résultat ne démontre pas que l’agent possède une expérience subjective de ses souvenirs.

# 22. Critères de progression du projet

SoiNesis ne devra passer à une phase plus complexe que si :

- les mécanismes précédents sont documentés ;
- les mesures sont automatisables ;
- les tests d’ablation sont possibles ;
- les résultats sont suffisamment reproductibles ;
- les facteurs de confusion majeurs sont identifiés ;
- les risques techniques sont contrôlés ;
- les mécanismes de sauvegarde et d’arrêt fonctionnent ;
- les résultats négatifs sont conservés.

Une architecture complexe sans protocole fiable ne constitue pas un progrès scientifique.

---

# 23. Conclusion provisoire

L’hypothèse directrice de SoiNesis est que certaines propriétés associées à la conscience pourraient dépendre de l’intégration progressive de mécanismes cognitifs, corporels, développementaux, sociaux et évolutifs.

Cette hypothèse reste :

- **possible** sur le plan théorique ;
- **partiellement testable** sur le plan fonctionnel ;
- **inconnue** concernant la conscience phénoménale.

Le projet commencera donc par les fonctions les plus simples à isoler et à mesurer.

L’ordre recommandé est :

1. mémoire et traçabilité ;
2. modèle de soi et métacognition ;
3. objectifs, temps et intégration ;
4. incarnation virtuelle ;
5. développement individuel ;
6. interactions sociales et culture ;
7. évolution artificielle.

Chaque étape devra pouvoir échouer sans que le projet réinterprète automatiquement cet échec comme une preuve cachée de conscience.
